# Menta — media V1

Revisión: 2026-09-30.

La ficha editorial **Menta** corresponde al género `Mentha L.`. Por eso ninguna fotografía o lámina se usa como representación diagnóstica de todo el género. Cada asset se rotula con el taxón que realmente muestra.

## Set visual

1. **Apertura — Mentha spicata L.**
   - Adaptación editorial transparente utilizada localmente en `public/images/menta/menta-thome-transparent.png`.
   - Basada en la lámina histórica de Otto Wilhelm Thomé, 1885.
   - Fuente histórica: Wikimedia Commons, `File:Illustration Mentha spicata0.jpg`, dominio público / PD-scan.
   - Uso: apertura editorial sin el papel oscuro de la digitalización original. Se mantiene rotulada como *Mentha spicata*, ejemplo del género, nunca como representación diagnóstica de todo *Mentha*.

2. **Evidencia — Mentha × piperita L.**
   - Foto de hábito de H. Zell, 2009.
   - Wikimedia Commons: `File:Mentha x piperita 001.JPG`.
   - CC BY-SA 3.0 / GFDL.
   - Uso: acompaña evidencia clínica que corresponde específicamente a peppermint.

3. **Hábitat / cultivo — Mentha spicata L.**
   - Foto de AnRo0002, 2016, Hockenheim.
   - Wikimedia Commons: `File:20160813Mentha spicata1.jpg`.
   - CC0 1.0.
   - Uso: ejemplo contextual de una especie del género.

4. **Precauciones — Mentha pulegium L.**
   - Foto de EmirDzaferovic, 2019.
   - Wikimedia Commons: `File:Mentha Pulegium 10.jpg`.
   - CC0 1.0.
   - Uso: acompaña el bloque específico sobre pennyroyal/poleo; nunca debe quedar visualmente asociado a peppermint.

## Regla de licencia

Cada item del manifest `src/data/menta-media.json` lleva `licenseVerifiedAt` y `verificationMethod`. La verificación se hace contra la página individual del archivo, no contra la categoría o el sitio general. Si en el futuro se reemplaza un asset, se repite la comprobación y se actualiza la fecha.

La apertura editorial de *M. spicata* se sirve como asset local transparente; las fotografías documentales continúan sirviéndose desde Commons durante el study. Si se aprueba el set para producción, también pueden copiarse al repositorio manteniendo nombre de origen, fuente, autor, licencia y fecha de verificación.
